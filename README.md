# mscx

Full-stack приложение для управления коллекциями аудиозаписей с возможностью offline режима.

## Технологический стек

### Клиент

- nuxt (as SPA)
- pinia
- tailwindcss
- @nuxt/ui
- vue-router
- @vueuse/core
- dexie

### Сервер

- go
- echo
- gORM / sqlite

## Начало работы

### Предварительные требования

- [bun](https://bun.sh/) (для клиента)
- Go 1.24+
- make
- git

### Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/locwid/mscx.git
cd mscx
```

2. Установите зависимости клиента:

```bash
bun install
```

3. Установите зависимости сервера:

```bash
go mod tidy
```

4. Настройте переменные окружения в Makefile (optional):

5. Запустите серверы разработки:

```bash
make dev
```

Приложение будет доступно по адресу:

- Клиент: http://localhost:3000
- Сервер: http://localhost:4000

### Сборка

Текцущий Makefile ориентирован на кросс-компиляцию для linux/amd64

```bash
make package
```

## Структура проекта

```
├── web/                 # Nuxt frontend приложение
│   ├── app/

```

## Описание ключевых функций

### Режим работы

- PWA
- Офлайн режим с дальнейшей синхронизацией

### Управление аудиозаписями

- Загрузка нескольких аудиозаписей одновременно
- Файловое хранилище с отслеживанием метаданных в базе данных
- Воспроизведение аудиозаписей
- Возможность загрузить / удалить аудиофайл для оффлайн использования

### Система плейлистов

- Создание пользовательских плейлистов
- Добавление и удаление аудиозаписей в плейлисты
